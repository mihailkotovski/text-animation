# Text Animation

Плагин для [exteraGram](https://exteragram.app), который оживляет набор текста: буквы мягко появляются, курсор плывёт, а стёртые символы рассыпаются на частицы.

**Версия 12.0** · exteraGram `>= 12.5.1` · авторы @itskotovski и @mishabotov

## Установка

1. Скачайте [`text_animation.plugin`](text_animation.plugin).
2. Откройте файл в exteraGram и подтвердите установку.
3. Настройки — в карточке плагина. Вверху экрана есть живой предпросмотр, изменения видны сразу.

Файл самодостаточен: Java-ядро уже встроено в него и проверяется по SHA-256 перед загрузкой.

## Возможности

### Появление букв

- появление из размытия, въезд сверху, рост из точки и доворот — в любых сочетаниях;
- четыре скорости и шесть кривых движения: мягкая, ровная, плавная, с перелётом, пружина, отскок;
- анимированная буква рисуется самим layout поля, поэтому жирный, курсив, моноширинный текст и ссылки сохраняют стиль на всём протяжении анимации.

### Удаление

- плавное исчезновение: анимация появления проигрывается назад;
- буквы рассыпаются в пыль, снежинки, лепестки сакуры или в собственные копии;
- падающие буквы с физикой: отскакивают от дна и стенок поля и катятся;
- частицы стартуют с контура глифа, вылетают за пределы поля ввода и не обрезаются его границами;
- при отправке сообщения текст взрывается и втягивается в кнопку отправки.

### Курсор

- плавное перемещение с выбором скорости и мягкое мигание;
- «жидкий» режим: курсор тянется при движении, подпрыгивает на пробеле, ныряет на переносе строки и сжимается при удалении.

### Прочее

- вибро-отклик на рассыпание и отправку;
- корректная работа с составными символами и эмодзи, RTL определяется автоматически;
- поля с паролями не анимируются;
- интерфейс настроек на русском и английском.

## Как это устроено

Плагин состоит из двух частей:

| Часть | Что делает |
| --- | --- |
| [`text_animation.plugin`](text_animation.plugin) | Python-обёртка: метаданные, экран настроек, проверка и загрузка DEX, передача настроек в ядро |
| [`src/`](src) | Java-ядро: хуки на поле ввода и вся отрисовка |

Ядро ставит Xposed-хуки на `EditTextBoldCursor.onDraw` и `setAllowDrawCursor` и на `ChatActivityEnterView.sendMessage` / `sendMessageInternal`. Изменения текста оно получает через `TextWatcher` и сужает каждую правку по общему префиксу и суффиксу, поэтому замена слова клавиатурой не перезапускает анимацию всего слова. Анимируемые буквы на время анимации вырезаются из отрисовки поля через `clipOutRect` — текст пользователя и его спаны не изменяются. При выгрузке плагина хуки снимаются, а системный курсор возвращается в исходное состояние.

| Файл | Назначение |
| --- | --- |
| `TextAnimationCore` | точка входа: bridge для Python, хуки, реестр полей |
| `Input` | состояние одного поля: разбор правок, связь эффектов, отправка |
| `Glyphs`, `Ghosts`, `Ghost`, `Motion` | появление и исчезновение букв |
| `Particles`, `Particle`, `ParticleLayer` | пул, физика и отрисовка частиц поверх окна |
| `Caret` | курсор |
| `Config` | настройки, пришедшие из Python |
| `Telegram`, `Clusters`, `Easing`, `Logs` | вспомогательные классы |

## Сборка

Нужны JDK 17 и Python 3. Положите в папку `libs/` рядом с `build.py`:

| Файл | Откуда взять |
| --- | --- |
| `libs/android-35.jar` | `android.jar` из Android SDK Platform 35 |
| `libs/hook.jar` | Xposed API из [Aliuhook](https://github.com/Aliucord/hook) |
| `libs/build-tools/lib/d8.jar` | Android SDK Build Tools |
| `libs/build-tools/dexdump.exe` | необязательно, используется для проверки результата |

Затем:

```bash
python build.py
```

Скрипт компилирует `src/*.java`, собирает `text_animation.dex`, встраивает его в `text_animation.plugin` и обновляет там SHA-256.
