# Text Animation

Плагин для [exteraGram](https://exteragram.app), который оживляет набор текста: буквы мягко появляются, курсор плывёт, а стёртые символы рассыпаются на частицы.

**Версия 11.0** · exteraGram `>= 12.5.1` · Plugin SDK `>= 1.4.4.2` · авторы @mihailkotovski и @mishabotov

## Установка

1. Скачайте [`text_animation.plugin`](text_animation.plugin).
2. Откройте файл в exteraGram и подтвердите установку.
3. Настройки — в карточке плагина. Вверху экрана есть живой предпросмотр, изменения видны сразу.

Файл самодостаточен: Java-ядро уже встроено в него и проверяется по SHA-256 перед загрузкой.

## Возможности

### Появление букв

- появление из размытия, въезд сверху, масштаб и поворот — в любых сочетаниях;
- шесть кривых движения: мягкая, ровная, плавная, с перелётом, пружина, отскок;
- подсветка новых букв цветом темы: буква загорается и остывает до цвета текста;
- вставленный текст проявляется волной и может собираться из частиц.

### Удаление

- плавное исчезновение: анимация появления проигрывается назад;
- буквы рассыпаются в пыль, искры, снежинки, лепестки сакуры или в собственные копии;
- падающие буквы с физикой: отскакивают от дна и стенок поля и катятся;
- частицы стартуют с контура глифа, а не из случайных точек.

### Частицы

- вылетают за пределы поля ввода и не обрезаются его границами;
- при отправке сообщения летят к кнопке отправки;
- падают по наклону телефона;
- разлетаются от курсора.

### Курсор

- плавное перемещение и настраиваемое мигание;
- «жидкий» режим: курсор тянется при движении, подпрыгивает на пробеле и ныряет на переносе строки;
- живые края выделения.

### Живая печать и реакции

- комбо за скорость печати: счётчик, искры, тряска на круглых значениях, буквы накаляются;
- реакции на `!`, `?`, эмодзи и слова: «снег», «сакура», «ура», «огонь», `snow`, `sakura`, `hooray`, `wow`, `fire`;
- вибро-отклик.

### Прочее

- корректная работа с составными символами и эмодзи;
- поддержка RTL-текста (включается отдельно);
- поля с паролями не анимируются;
- интерфейс настроек на русском и английском.

## Как это устроено

Плагин состоит из двух частей:

| Часть | Что делает |
| --- | --- |
| [`text_animation.plugin`](text_animation.plugin) | Python-обёртка: метаданные, экран настроек, проверка и загрузка DEX, передача настроек в ядро |
| [`src/`](src) | Java-ядро: хуки на поле ввода и вся отрисовка |

Ядро ставит Xposed-хуки на `onDraw`, `onFocusChanged` и `onTouchEvent` класса `EditTextBoldCursor` и на `ChatActivityEnterView.sendMessage`. При выгрузке плагина хуки снимаются, системный курсор и текст возвращаются в исходное состояние.

| Файл | Назначение |
| --- | --- |
| `TextAnimationCore` | точка входа: хуки, состояние полей, цикл анимации |
| `CharAnimator` | появление и исчезновение букв |
| `ParticleSpawner`, `Particle`, `ParticleRenderer` | создание, физика и отрисовка частиц |
| `ParticleOverlay` | слой частиц поверх окна |
| `CursorRenderer` | курсор и края выделения |
| `PowerMode` | комбо, тряска, счётчик |
| `TiltSensor` | наклон устройства |
| `Settings` | значения настроек, пришедшие из Python |
| `TelegramReflection`, `ViewHelper`, `GraphemeClusters`, `Easing`, `AnimLog` | вспомогательные классы |

## Сборка

Нужны JDK 17 и Python 3. Положите в папку `libs/` рядом с `build.py`:

| Файл | Откуда взять |
| --- | --- |
| `libs/android-35.jar` | `android.jar` из Android SDK Platform 35 |
| `libs/hook.jar` | Xposed API из [Aliuhook](https://github.com/Aliucord/hook) |
| `libs/build-tools/lib/d8.jar` | Android SDK Build Tools |
| `libs/build-tools/dexdump.exe` | необязательно, используется для проверки результата |

Затем:

```bash
python build.py
```

Скрипт компилирует `src/*.java`, собирает `text_animation.dex`, встраивает его в `text_animation.plugin` и обновляет там SHA-256.
